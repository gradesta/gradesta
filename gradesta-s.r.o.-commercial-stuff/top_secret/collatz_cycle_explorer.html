Cycle Analysis

This tool explores potential cycles in the Collatz conjecture using the condensed graph approach. We analyze cycles of length n by examining sequences of k values representing the number of divisions by 2 between each "3n+1" operation.

General Cycle Equation

For a cycle of length n with k-values $k_0, k_1, \ldots, k_{n-1}$:

n = 1: $x = \frac{2^1 - 2^{k_0-1}}{2^{k_0} - 3^1}$

n ≥ 2: $x = \frac{2^{k_{n-1}+1}\left(2^{k_0 + k_1 + \cdots + k_{n-2} + 1} + 2^{k_1 + k_2 + \cdots + k_{n-2}} + \cdots + 2^{k_{n-2}} + 1\right) - 2^n}{3^n - 2^{k_0 + k_1 + \cdots + k_{n-1}}}$
