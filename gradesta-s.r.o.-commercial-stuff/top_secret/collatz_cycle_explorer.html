Cycle Analysis

This tool explores potential cycles in the Collatz conjecture using the condensed graph approach. We analyze cycles of length n by examining sequences of k values representing the number of divisions by 2 between each "3n+1" operation.

Cycle Equation

For a cycle of length n with k-values $k_0, k_1, \ldots, k_{n-1}$, we solve the nested equation:

Original Form: $x = \frac{6\left(\frac{6\left(\cdots\frac{6x + 4}{2^{k_0+1}} - \frac{1}{2}\cdots\right) + 4}{2^{k_{n-1}+1}} - \frac{1}{2}\right) + 4}{2^{k_{n-1}+1}} - \frac{1}{2}$

Simplified Form: $x = T_{k_{n-1}}(T_{k_{n-2}}(\cdots T_{k_0}(x) \cdots))$

where $T_k(x) = \frac{3x + 2}{2^k} - \frac{1}{2}$

n = 1: $x = \frac{2 - 2^{k_0-1}}{2^{k_0} - 3}$

n ≥ 2: Solved numerically by finding the fixed point of the nested transformation.
