Generalized Collatz Equation Calculator - Base 3 Analysis

Instructions: Enter comma-separated k values and x value. The calculator automatically infers the cycle length (n) from the number of k values entered and uses the generalized formulas to compute the Collatz equation.

Key Parameters:
• n: Number of odd steps in the cycle (automatically inferred from k values)
• k values: Division factors for each odd step (k₀, k₁, ..., kn-1)
• x: Variable parameter in the equation
• K: Sum of all k values
• m: floor(K/2)
• p: floor((K+1)/2)
