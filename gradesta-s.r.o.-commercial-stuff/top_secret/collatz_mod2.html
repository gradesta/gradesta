Collatz Binary Visualization

Position: 0 | Value: 0 | Use arrow keys to move, space to flip bit

About This Visualization

This visualization shows the Collatz operations 3n+1 in a special type of binary arithmetic where leading zeros are automatically trimmed, so that n×2^k ≡ n×2^l for any k,l ≥ 0.

Grid Colors:
• Grey cells represent binary 0s
• Green cells represent binary 1s in the main sequence
• Red cells represent intermediate calculations (shifted left and +1)

Controls:
• Use ← → arrow keys to move the cursor
• Press spacebar to flip the current bit
• Use ↑ ↓ arrow keys to scroll vertically through the grid
• Hold Shift + ← → arrow keys to scroll horizontally
• Toggle the checkbox to enable/disable the +1 operation
• Click Reset button to clear the editable row

The algorithm works as follows: For each green row, we create red rows below it: 1. A red row with the same bits shifted one position to the left (representing 2n) 2. A red row with a single 1 bit aligned to the rightmost position (representing +1, if enabled) Then we add these rows together to get the next green row, which becomes the input for the next iteration.
